# 教育訓練排班系統

網站在本機以 SQLite 儲存資料；部署到 Render 時以 Turso 雲端資料庫儲存資料。第一版沒有登入功能，任何知道網址的人均能查看與修改資料。

## 啟動

電腦需安裝 Node.js 24 以上。Windows 可雙擊 `start-local.cmd`；首次啟動會安裝套件並建置畫面。看到「教育訓練排班」網址後，在瀏覽器開啟 [http://127.0.0.1:3000](http://127.0.0.1:3000)。關閉命令視窗即停止服務，資料仍保存在 SQLite 檔案中。

也可在此資料夾執行：

```powershell
npm ci
npm run build
npm start
```

若要一邊修改程式一邊預覽，執行 `npm run dev` 並開啟 `http://127.0.0.1:5173`。

## 操作順序

1. 在「學員名冊」下載匯入範例，填妥後匯入 CSV 或 XLSX，也可逐筆新增。單位、姓名、普查職位組合相同的資料會略過，其他匯入欄位保存在「其他欄位」。
   學員可編輯、退訓或永久刪除。永久刪除會釋出此人的座位並移除其考核註記；若所屬場次已鎖定，則不能刪除。
2. 在「教室座位圖」建立教室並設定欄列數。用「畫座位」點選格子；用「留走道空白」點選兩欄之間的窄條，即可加寬欄間距，**不占英文字母欄位，也不顯示走道文字**；用「放講台」設定講台。位置圖共用於同一教室的所有場次。欄號為 A～Z、AA～AZ，列號為數字。
   教室卡片可刪除教室及位置圖，同時刪除其所有場次、釋出學員座位；若教室有已鎖定場次，則不能刪除。
3. 在「場次排班」建立日期與教室。左側可依機關、已配置／未配置及關鍵字篩選名單；將學員拖到右側藍色空位即可排班，也可以先點學員再點空位。放入後會顯示「已配置」；在排班頁再點一次綠色座位，會釋出座位並恢復「未配置」。改期或換位則將已配置學員移到新場次的空位。紫色為講台。
   選擇場次後可「修改日期」或「刪除場次」。修改日期時可保留原配置，讓所有已配置學員隨場次改期；也可將該場次所有學員改回未配置。刪除場次會釋出全部學員。重設或刪除配置也會移除其考核註記，操作後可在異動紀錄查看。
4. 在獨立的「教育訓練考核」頁選場次，點有學員的座位填考核狀態和註記。這一頁無法排班、改期或釋出座位。
5. 在「列印與匯出」取得座位圖、考核表、簽到表、學員名冊及場次清單。下載的座位圖是可離線開啟與列印的 HTML；若需 PDF，可在列印視窗選「另存為 PDF」。

台灣時間今天 15:00 起，明天的場次不可再新增場次、安排或更換座位、改期及退訓釋位；今天及過去場次也鎖定。考核註記仍可填寫。伺服器端會再次檢查時間與座位，兩人同時選同一座位時僅一人成功。

## 資料庫與備份

- SQLite 檔：`data/scheduler.sqlite`。首次啟動時自動建立，後續啟動會沿用既有資料。
- 在專案資料夾執行 `npm run backup`，會把運作中的資料庫安全複製到 `backups/`，可定期備份。
- `data/` 與 `backups/` 不應上傳到公開 GitHub，因為可能包含學員資料。原始碼的 `.gitignore` 已排除這些資料夾。
- 換電腦時，先停止網站，再把 `data/scheduler.sqlite` 複製到新電腦相同專案的 `data/` 目錄。

## 驗證

執行 `npm test`，會使用獨立的暫存資料庫測試匯入去重、座位衝突、改期、退訓、座位圖與 15:00 規則。測試資料不會寫入正式的 `data/scheduler.sqlite`。

## 對外使用：Render + Turso

1. 在 Turso 免費方案建立資料庫與資料庫權杖，記下資料庫網址（`libsql://...`）和權杖。不要將權杖放入 GitHub。
2. 在 Render 建立 Blueprint，連接此 GitHub 儲存庫。`render.yaml` 會建立免費的 Web Service；在環境變數欄填入 `TURSO_DATABASE_URL` 與 `TURSO_AUTH_TOKEN`。首次啟動會自動建立資料表。
3. 如要將本機現有資料搬到雲端，先確認 Render 網站已啟動，再於本機設定相同的兩個環境變數，執行 `npm run migrate:turso`。此指令只匯入到空的 Turso 資料庫，避免覆蓋已有資料。請勿把本機資料庫或權杖提交到 GitHub。
4. Render 提供 `onrender.com` 公開網址。免費服務閒置後會休眠，再次開啟可能需要約一分鐘；網站檔案系統是暫時性的，所以正式資料必須放在 Turso。

本機未設定 `TURSO_DATABASE_URL` 時，繼續使用 `data/scheduler.sqlite`。Turso 免費方案與 Render 免費方案各有用量上限，請在各自控制台查看實際使用量。不要加上付款方式或啟用付費方案，除非您打算付費。
